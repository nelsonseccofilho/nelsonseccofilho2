# Portfolio Build Kit v1.0

This ZIP is the **pre-development handoff** for the new Senior Product Designer portfolio.

## Copy into the Next.js repository
Copy the `public/assets` folder to the project's `public/assets` directory. Keep `planning`, `design-system` and `provenance` in `/docs/portfolio/` (or equivalent) so the rules remain versioned with the code.

## Visual direction
Light theme by default, optional dark theme, Xbox Green `#107C10` as a controlled accent, generous editorial whitespace, evidence-led project storytelling, restrained microinteractions. References such as OpenAI, Apple and Samsung are quality benchmarks only — do not clone their UI.

## Non-negotiables
- NN/g principles as UX quality guardrail.
- Conventional Commits.
- BEM for semantic custom CSS naming.
- No feature without a basic test.
- Validate 1920+, 1366, tablet and mobile.
- SEO/performance planned from foundation, not patched at the end.
- Never fabricate product evidence.

## Asset policy
HORIZON/DCC visuals derive from existing case material. DASA is confidentiality-safe editorial representation. SUBITER/ConnectCar covers/support visuals are deliberately editorial representations until publication clearance / exact product attribution is confirmed.

Start implementation only after reading `planning/01-development-roadmap.md`, `planning/02-definition-of-done.md` and `provenance/assets-manifest.json`.
