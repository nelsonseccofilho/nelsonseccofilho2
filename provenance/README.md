# Provenance Rules

The package separates **evidence** from **editorial representation**.

- `evidence`: derived from existing case material / documented product artifact.
- `editorial representation`: newly composed to communicate verified concepts without pretending to reproduce the original UI.
- `review_privacy`: requires explicit privacy review before public launch.
- `review`: requires naming/publication confirmation before being presented as public project evidence.

Read `assets-manifest.json` before wiring a visual into a claim.
